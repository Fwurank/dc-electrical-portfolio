Portfolio / Project 02

02 · Load & equipment sizing tool

dcsizing is a Python package and Streamlit app. It works from IT load to facility load, then sizes every power-train element in normal and failure modes and compares the result with the phase-1 ratings.

Key findings

  • Campus design peak is 37.8 MW at +32 °C. Adding the non-coincident UPS recharge gives 42.6 MW, which is above the 40 MW subscription. That result drives the recharge rule and project 04.
  • Block transformer 2 500 kVA at 82 % in N-1, IT genset 2 750 kVA at 88 %, MSB I″k 53.8 kA at the transformer terminals (IEC 60909 with KT).
  • The battery per 1 000 kW UPS module is governed by C-rate, not autonomy: 120 kWh would run at 10.7 C at end of life, against 8 C max, so it goes to 165 kWh.
  • Annualised PUE is 1.165 at 75 % IT from climate bins. The ≤ 1.15 target needs a mechanical pPUE of ≲ 0.035 in free-cooling hours. 11 rating changes were raised; 46 tests, including 2 Streamlit AppTests.
