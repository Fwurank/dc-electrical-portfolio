Portfolio / Project 01

01 · Design basis & single-line diagrams

DB-001 Rev P2 and an eight-sheet A3 single-line diagram set for the fictional 30 MW IT campus. Everything is generated from Python, so a rating change in the design basis is a one-line change in a sheet script.

Key findings

  • The architecture is distributed redundant 4N/3 at the block level and 2N mechanical. It was compared against 2N, N+1 and block-redundant options.
  • Rev P2 brings in all 31 rating changes from projects 02–04 (battery 165 kWh, rectifier breaker 2 000 A, busbar trunking, interlocks, arc protection, CT ratios, BESS bays…). A traceability table links each change to its source.
  • IEC 60617 symbols: CTs with ratio and class, VTs, surge arresters, earthing switches, relay function numbers (50/51, 67N, 87T, 81…), meters, Petersen coil, arc sensors and interlocks.
  • The automated drawing checker measures 1 199 texts: minimum cap height 2.57 mm on A3, tags 3.6 mm, drawing number 3.6 mm, 0 overlaps.
This is a fictional case built from public standards and assumed parameters marked [ASSUMED] / (A). No employer, client or vendor data is used.
